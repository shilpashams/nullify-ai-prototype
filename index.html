Run It Locally or Deploy in Minutes

No build tools, no package installs. Open a file and it works.

1

Clone the repo

Pull the project to your machine with Git, or download the ZIP from GitHub.

# Clone
git clone https://github.com/
YOUR_USERNAME/nullify-ai-prototype

# Enter project
cd nullify-ai-prototype
2

Open locally

Double-click index.html to open in your browser. No server needed — all four demos work as local files.

# Or serve with Python
python3 -m http.server 3000

# Then open
http://localhost:3000
3

Deploy to the web

Drag the project folder onto netlify.com/drop for an instant live URL. Or enable GitHub Pages in your repo settings.

# GitHub Pages
Settings → Pages →
Source: main branch
Folder: / (root)

# Live at:
username.github.io/nullify-ai-prototype
