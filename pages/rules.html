Global Alert Thresholds

Defaults applied to all agents unless overridden

Drift Score — Warning 40/ 100
Agent transitions to Warning status. Compliance team notified via Slack.
Drift Score — Critical 70/ 100
Agent transitions to Critical. PagerDuty P1 fires. Auto-block prompt shown.
Violations per 24h — Warning 10violations
Sustained violations trigger warning escalation regardless of drift score.
Violations per 24h — Critical 30violations
Critical escalation path fires. Suggested action: pause agent.
Block Rate Change — Alert 50% change
Alert fires when block rate shifts more than this % in either direction within 48h. Catches both "too many blocks" and FraudScanner-X type collapses.
